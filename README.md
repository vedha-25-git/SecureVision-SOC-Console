# SecureVision SOC Console

## Overview
SecureVision SOC Console is a Security Operations Center (SOC) Alert Management Dashboard developed using Flask, SQLite, HTML, CSS, and Chart.js.

## Features
- Add security alerts
- Search alerts
- Filter alerts by severity
- Update alert status
- Delete alerts
- Dynamic alert counters
- Analytics dashboard with charts
- Responsive design

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

  
## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/vedha-25-git/SecureVision-SOC-Console.git
```

### 2. Navigate to the Project

```bash
cd SecureVision-SOC-Console
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

```
http://127.0.0.1:5000
```
