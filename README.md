# SecureVision SOC Console

## Overview
SecureVision SOC Console is a Security Operations Center (SOC) Alert Management Dashboard developed using Flask, SQLite, HTML, CSS, and Chart.js.

## Features
- Add security alerts
- Search alerts
- Filter alerts by severity
- Update alert status
- Delete alerts
- Dynamic alert counters
- Analytics dashboard with charts
- Responsive design

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js

## Installation

1. Install Python
2. Install Flask

pip install flask

3. Run the application

python app.py

4. Open

http://127.0.0.1:5000
